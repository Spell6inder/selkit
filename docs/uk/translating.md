# Переклад Selkit

[English](../translating.md) · **Українська**

Переклади — це gettext-файли `.po` у [`resources/locales`](../../resources/locales). Почніть із шаблону `selkit.pot` у [Poedit](https://poedit.net/) або на будь-якій платформі перекладу.

Переклад можна спробувати без збирання: покладіть `xx.po` у `%APPDATA%\selkit\locales` (у Linux — `~/.config/selkit/locales`) і перезапустіть Selkit. Файл звідти також має перевагу над вбудованим перекладом, а рядки, яких у ньому бракує, показуються англійською.

Щоб переклад став вбудованим, додайте файл у `resources/locales`. Тести перевіряють, що він охоплює всі рядки й зберігає ті самі `%`-підстановки.

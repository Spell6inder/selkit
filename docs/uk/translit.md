# Правила транслітерації

[English](../translit.md) · **Українська**

Пункти меню **Латинкою** / **З латинки** працюють за системами, описаними у звичайних текстових файлах `.rules`.

**Вбудовані системи** лежать у [`resources/translit`](../../resources/translit):

| Файл | Система | Назад до оригінального письма |
|---|---|---|
| `iso9.rules` | ISO 9:1995: кожній літері кирилиці відповідає рівно одна латинська, з діакритикою. Також основа для національних систем | точно |
| `uk.rules` | українська, офіційна (постанова КМУ № 55 від 2010 року), як у паспортах | найімовірніший варіант |
| `bg.rules` | болгарська, офіційна (Закон про транслітерацію, 2009) | найімовірніший варіант |
| `sr.rules` | сербська латинка | точно |
| `ja.rules` | японська кана, модифікований Гепберн. Кандзі лишаються як є | — |

**Як вибирається система.** Основний пункт вибирає систему сам:
1. за літерами, характерними для мови (і ї є ґ → українська, ђ ћ џ љ њ ј → сербська, ъ → болгарська);
2. потім за мовою інтерфейсу;
3. потім за пріоритетом.

Підменю **Латинкою за** показує всі системи, що підходять до тексту, а **Повторити** запам'ятовує вибрану.

## Власні правила

Покладіть файли `.rules` у `%APPDATA%\selkit\translit` (у Linux — `~/.config/selkit/translit`) і перезапустіть Selkit.
- Файл з назвою вбудованого (`uk.rules`) замінює його.
- Нова назва додає систему.
- Зламані файли пропускаються, а помилка пишеться в лог.

Невеликий приклад: змінює одну літеру української системи, а решту бере з ISO 9:

```ini
name    = Ukrainian (mine)
name.uk = Українська (моя)
lang    = uk
base    = iso9
detect  = і ї є ґ

[to-latin]
щ = sch
```

## Формат

Файл — текст у UTF-8. Спочатку йдуть налаштування заголовка `ключ = значення`, далі секції з правилами `що = на що`.

- **Коментарі.** `#` починає коментар на початку рядка або після пробілу.
- **Escape-послідовності.** У значеннях можна писати `\uXXXX`, наприклад `ґ = g\u0300` для комбінованого наголосу.

**Заголовок**

| Ключ | Значення |
|---|---|
| `name`, `name.<мова>` | Назва для показу, за потреби окремо для мови інтерфейсу (`name.uk`) |
| `lang` | Мова системи. Їй надається перевага, якщо це мова інтерфейсу |
| `base` | Інша система, правила якої доповнюють літери, не задані тут |
| `detect` | Літери, які вказують на цю систему під час автовибору |
| `detect-latin` | Літери, без яких латинський текст цією системою назад не перетворюється (використовує ISO 9) |
| `priority` | Що вибрати при рівності під час автовибору; більше перемагає, типово 0 |
| `reverse` | `rules` бере секцію `[from-latin]` (типово, якщо вона є). `auto` обертає `[to-latin]`, що підходить для систем «одна літера — одна літера». `no` вимикає зворотний напрямок |
| `silent` | Символи, які відкидаються між двома перетвореними літерами, як-от апострофи |
| `fold-katakana` | `yes`: катакана перетворюється правилами для хірагани |
| `space-between-scripts` | `yes`: відокремлювати перетворені слова від сусідніх слів іншим письмом (`葬送のフリーレン` → `葬送 no Furīren`) |
| `capitalize-scripts` | Письма, перетворені слова з яких починаються з великої літери, наприклад `Katakana` |

**Секції**

- **`[to-latin]` (обов'язкова).** Правила перетворення.
- **`[from-latin]`.** Правила для зворотного напрямку.
- **`[after]`.** Заміни всередині кожного перетвореного слова, один прохід зліва направо. Японські правила так позначають подвоєні приголосні й довгі голосні.

**Правила**

| Правило | Значення |
|---|---|
| `г = h` | Одна літера |
| `зг = zgh` | Кілька літер; перемагає найдовший збіг |
| `^є = ye` | Лише на початку слова |
| `ия$ = ia` | Лише в кінці слова |
| `ь =` | Порожнє: літера відкидається |

Регістр під час пошуку не важить, а результат повторює оригінал: `Щука` → `Shchuka`, `ЩУКА` → `SHCHUKA`. Символи без правила лишаються як є.

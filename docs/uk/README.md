# Selkit

[English](../../README.md) · **Українська**

Інструменти для виділеного тексту: на середній кнопці миші у Windows, на клавіші в Linux.

- **Primary selection, як у Linux, — у Windows.** Виділіть текст будь-де і вставте його середньою кнопкою. Звичайний буфер обміну лишається як був.
- **Меню перетворень** для виділеного тексту:
  - виправити розкладку (`ghbdsn` → `привіт`);
  - змінити регістр (camelCase, snake_case, ВЕЛИКІ…);
  - транслітерувати латинкою і назад, за офіційними системами й власними правилами;
  - упорядкувати пробіли й рядки;
  - закодувати чи розкодувати URL і Base64.
- **Плагіни:** власні пункти меню у вигляді скриптів чи програм будь-якою мовою.
- **Повтор останньої дії** без відкриття меню.

| | Windows 10/11 | Linux |
|---|---|---|
| Primary selection | ✔ | уже є в системі |
| Меню перетворень | Shift + середня кнопка | команда `selkit menu` на клавіші, яку ви виберете |
| Виправлення розкладки | ✔ | — |
| Інтерфейс | англійська, українська | англійська, українська |

## Встановлення

Завантажте з [Releases](https://github.com/Spell6inder/selkit/releases):
- **Windows:** `selkit.exe`. Покладіть будь-куди й запустіть; програма живе в області сповіщень.
- **Linux:** `selkit-*-linux-*.tar.gz`. Що ще потрібно, див. у [Linux](linux.md).

Або зберіть з Go 1.27+:

```bash
go install -ldflags "-H=windowsgui" github.com/Spell6inder/selkit/cmd/selkit@latest
```

У Linux — без `-ldflags "-H=windowsgui"`.

## Приватність

Selkit читає виділений текст лише для того, щоб вставити чи перетворити його. Нічого нікуди не надсилається, мережевого коду немає. Сам текст у лог не пишеться, якщо ви цього не ввімкнете.

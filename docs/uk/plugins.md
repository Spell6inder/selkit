# Плагіни

[English](../plugins.md) · **Українська**

Плагін додає в меню перетворень власні пункти. Це будь-яка програма чи скрипт, що читає виділений текст зі stdin і пише результат у stdout, тож писати плагін можна будь-якою мовою. Той самий плагін працює і у Windows, і в Linux.

Готовий приклад — [`examples/plugins/brackets`](../../examples/plugins/brackets): бере текст у дужки або прибирає їх, з PowerShell-скриптом для Windows і shell-скриптом для Linux.

## Вбудовані модулі

Частина меню вбудована в програму, але показується й вимикається як плагін:

| Модуль | Що робить |
|---|---|
| `translit` | Латинкою й назад, за кількома системами ([транслітерація](translit.md)) |
| `encoding` | URL і Base64: закодувати й розкодувати |
| `quotes` | «Ялинки», “лапки-коми”, "прямі" лапки й зворотні апострофи, а також прибрати лапки |

Вони працюють усередині програми, тож прев'ю в них завжди є й нічого не коштує. Їхні назви зайняті: папка плагіна з такою назвою не завантажується.

## Встановлення

**Налаштування → Плагіни** мають рядок для джерела: папки, zip-файла, посилання на zip-файл або репозиторію GitHub у вигляді `github.com/власник/репозиторій`. У Linux те саме робить команда:

```bash
selkit plugins install ./brackets
selkit plugins install brackets-1.0.zip
selkit plugins install https://example.com/brackets.zip
selkit plugins install github.com/owner/selkit-plugin-brackets
```

Перед встановленням Selkit показує плагін: назву, версію, джерело, команду, яку він запускає, і його дії, — і питає. У скрипті відповіддю є `--yes`. Папка називається за джерелом: як папка, як zip-файл без версії або як репозиторій без префікса `selkit-plugin-` чи `selkit-`; `--name=ID` задає іншу назву.

З GitHub Selkit бере найновіший реліз: прикріплений до нього `.zip`, а без нього — архів вихідного коду. Він запам'ятовує, звідки плагін і який це реліз, у `install.json` у папці плагіна, тож його можна оновлювати:

```bash
selkit plugins update
selkit plugins update brackets
selkit plugins remove brackets
```

Кнопка **Перевірити оновлення** в налаштуваннях робить те саме. Без вашого запиту нічого не завантажується, а плагін із папки чи zip-файла оновлювати нема звідки.

Плагін можна й скопіювати в папку плагінів вручну:
- Windows: `%APPDATA%\selkit\plugins` (її відкриває вкладка **Плагіни** в налаштуваннях);
- Linux: `~/.config/selkit/plugins`.

Плагіни читаються щоразу, коли відкривається меню, тож перезапуск не потрібен.

## Налаштування

**Налаштування → Плагіни** показують модулі й плагіни, і в кожного плагіна два прапорці:
- **назва плагіна** вмикає чи вимикає його;
- **Прев'ю в меню** запускає плагін під час відкриття меню, щоб показати результат поруч із пунктом і зробити пункт неактивним, коли дія не підходить. Без прев'ю пункт завжди доступний, а плагін запускається лише після вибору.

На прев'ю всі плагіни разом мають 0,3 с (у Linux — 0,5 с). Ті, що не встигли, показуються без прев'ю. Для повільних плагінів, як-от PowerShell-скриптів, яким лише на запуск треба близько 0,3 с, прев'ю краще вимкнути.

У Linux ті самі налаштування змінює команда; назва — це папка плагіна або назва модуля:

```bash
selkit plugins
selkit plugins disable encoding
selkit plugins enable brackets
selkit plugins preview brackets off
```

Вони зберігаються в `config.json`, який можна правити й вручну:

```json
"plugins": {
  "brackets": {"preview": true},
  "encoding": {"disabled": true}
}
```

## Як написати плагін

Плагін — це папка з `plugin.json`:

```json
{
  "name": "Brackets",
  "description": "Put the text in brackets or take them off",
  "version": "1.0",
  "commands": {
    "windows": ["powershell", "-NoProfile", "-ExecutionPolicy", "Bypass", "-File", "brackets.ps1"],
    "linux": ["sh", "brackets.sh"]
  },
  "timeout_ms": 5000,
  "preview": false,
  "actions": [
    {"id": "round", "name": "(Round brackets)"},
    {"id": "unwrap", "name": "Remove brackets"}
  ]
}
```

| Ключ | Значення |
|---|---|
| `name` | Назва плагіна в налаштуваннях і назва його підменю |
| `description` | Рядок під назвою в налаштуваннях; без нього показуються назви дій |
| `version` | Показується під час встановлення; для плагіна з GitHub замість неї показується реліз |
| `command` | Командний рядок, однаковий для всіх систем |
| `commands` | Командний рядок для кожної системи (`windows`, `linux`), замість `command` |
| `timeout_ms` | Скільки може тривати запуск; типово 2000 |
| `preview` | Чи ввімкнене прев'ю, доки користувач його не змінить; типово `true` |
| `actions` | Пункти меню: `id` (літери, цифри, `-` і `_`) та `name` |

Плагін з однією дією — окремий пункт меню, а з кількома отримує підменю. Якщо програма лежить у папці плагіна, вона запускається звідти, інакше шукається в `PATH`. Робоча папка — папка плагіна.

Щоб опублікувати плагін на GitHub, зробіть реліз із папкою плагіна в `.zip`, де `plugin.json` лежить згори або в одній папці всередині. Без такого файла береться архів вихідного коду релізу.

### Запуск

| | |
|---|---|
| stdin | Виділений текст, UTF-8 |
| stdout | Результат, UTF-8. Один кінцевий перенос рядка відкидається, якщо в тексті його не було, тож `print` підходить |
| `SELKIT_ACTION` | `id` вибраної дії |
| `SELKIT_LANG` | Мова інтерфейсу (`uk`, `en`) |
| `SELKIT_PREVIEW` | `1`, коли результат потрібен лише для прев'ю |
| код виходу 0 | Готово. Якщо результат збігається з текстом, пункт неактивний («Нічого змінювати») |
| код виходу 3 | Дія не підходить до цього тексту: пункт неактивний, а stderr пояснює чому |
| інші коди | Помилка; stderr показується користувачеві |

Запуск, довший за `timeout_ms`, зупиняється.

**Windows PowerShell** читає скрипт без BOM у кодуванні ANSI, а консоль у нього типово не в UTF-8. Почніть скрипт так:

```powershell
[Console]::InputEncoding = [Text.Encoding]::UTF8
[Console]::OutputEncoding = New-Object Text.UTF8Encoding $false
$text = [Console]::In.ReadToEnd()
```

Сам скрипт тримайте в ASCII або збережіть як UTF-8 з BOM.

### Переклад

Назви в `plugin.json` англійські. Переклади — це власні gettext-файли плагіна, `locales/<мова>.po` в його папці, де `msgid` — англійський текст із `plugin.json`:

```po
msgid "Remove brackets"
msgstr "Прибрати дужки"
```

Повідомлення в stderr — справа самого плагіна: перекладайте їх за `SELKIT_LANG`.

## Безпека

Плагін — звичайна програма з вашими правами, і він отримує виділений текст: встановлюйте лише плагіни, яким довіряєте. Selkit запускає лише те, що лежить у вашій папці плагінів, завантажує лише тоді, коли ви встановлюєте чи оновлюєте, і перед встановленням показує команду, яку запускатиме плагін.

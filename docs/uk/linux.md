# Selkit у Linux

[English](../linux.md) · **Українська**

У Linux primary selection уже є, тож там Selkit — лише меню перетворень: команда, яку призначають на клавішу чи кнопку миші в налаштуваннях робочого столу.

```bash
selkit menu
```

Вона бере виділений текст, показує дії з прев'ю в програмі меню і кладе результат і в буфер обміну, і в primary. Вставляйте його Ctrl+V або середньою кнопкою.

Дії в меню ті самі, що й у [Windows](windows.md#меню-перетворень), разом із [плагінами](plugins.md), крім виправлення розкладки: для нього потрібні таблиці розкладок Windows. Комбінацій миші теж немає, команду запускає робочий стіл.

## Команди

| Команда | Що робить |
|---|---|
| `selkit menu` | Меню перетворень для виділення |
| `selkit repeat` | Повторити останню вибрану в меню дію, без меню |
| `selkit apply ID` | Перетворити stdin у stdout: `echo Щука \| selkit apply translit` |
| `selkit list` | Показати ID дій (`translit`, `translit:uk`, `snake`, `base64-encode`…) |
| `selkit plugins` | Показати, встановити, оновити й видалити [плагіни](plugins.md) або змінити їхні налаштування |
| `selkit shortcut` | Показати, призначити й прибрати клавіші меню та повтору ([нижче](#гарячі-клавіші)) |
| `selkit version` | Показати версію |

Параметри `menu` і `repeat`:

| Параметр | Що робить |
|---|---|
| `-type` | Ще й надрукувати результат поверх виділення |
| `-clipboard` | Брати буфер обміну замість виділення |
| `-picker НАЗВА` | Програма меню замість типової: `fuzzel` на Wayland, `rofi` на X11 (лише для `menu`) |

`menu` і `repeat` беруть текст із каналу чи файла замість виділення. Результат тоді йде ще й у stdout, а друку поверх виділення немає:

```bash
echo 'test foo bar' | selkit menu
selkit repeat < notes.txt > result.txt
```

## Гарячі клавіші

Призначте типові клавіші, `Ctrl+Shift+Alt+X` на меню й `Ctrl+Shift+Alt+Z` на повтор, або свої; одну з них можна не вказувати:

```bash
selkit shortcut set --default
selkit shortcut set --menu=F9 --repeat=F7
```

`set` також встановлює іконку в `~/.local/share/icons` для налаштувань, сповіщень і рядка пошуку в меню `rofi`; коли прибрано обидві клавіші, вона теж зникає.

Результат замінює виділене; із `--no-type` він лише потрапляє в буфер. `--clipboard` бере буфер обміну замість виділення, а `--picker=НАЗВА` вибирає програму меню. Якщо клавіша зайнята, нічого не зміниться.

Подивитися, що призначено, або відкрити налаштування клавіатури робочого столу:

```bash
selkit shortcut status
selkit shortcut open
```

Перед видаленням програми приберіть клавіші. Налаштування, правила й плагіни лишаться в `~/.config/selkit`; щоб прибрати і їх, видаліть цю папку. Із `--menu` або `--repeat` прибирається лише ця клавіша.

```bash
selkit shortcut remove
```

Клавіша — це модифікатори (`Ctrl`, `Alt`, `Shift`, `Meta`) і назва клавіші через `+`. Selkit дає `menu` і `repeat` по одній клавіші, тож нове призначення переносить її, а клавішу, зайняту чимось іншим, команда не забере.

У KDE обидві дії — це одна група **Selkit** у налаштуваннях скорочень: **Запустити** там відкриває меню. Клавіші, які ви додали там самі, лишаються, коли Selkit змінює свою; `remove` прибирає і їх.

| Робочий стіл | `selkit shortcut set` |
|---|---|
| KDE Plasma (X11 і Wayland) | Призначає клавішу; потрібні ще `dbus-send` і `kbuildsycoca6` |
| Xfce | Призначає клавішу через `xfconf-query` |
| Sway, i3, Hyprland | Друкує рядок, який треба додати в конфігурацію |
| GNOME | Призначає клавішу через `gsettings`; ще не перевірено на справжньому столі |
| Інші | Друкує команду для налаштувань клавіатури робочого столу |

## Потрібні програми

Selkit працює з робочим столом через звичайні консольні програми, тож бібліотеки не потрібні:

| Для чого | Wayland | X11 |
|---|---|---|
| Виділення й буфер обміну | `wl-clipboard` | `xclip` або `xsel` |
| Меню | `fuzzel`, `wofi` або будь-яка з колонки X11 (на GNOME без `fuzzel` і `wofi`) | `rofi`, `bemenu`, `dmenu` або `zenity` |
| Друк тексту (`-type`) | `wtype` або `ydotool` | `xdotool` |
| Сповіщення | `notify-send` | `notify-send` |

Якщо команду запущено в терміналі й встановлено `fzf`, меню буде в ньому. Без `notify-send` повідомлення пишуться в термінал.

Меню — це один список із назвами груп як заголовками. У `rofi` заголовок вибрати не можна; в інших програмах його вибір просто знову відкриває меню. `↻` позначає дію, яку запустить `repeat`; `rofi` ще й підсвічує її.

Не кожен композитор Wayland підтримує primary selection; без нього користуйтеся `-clipboard`.

У Wayland `-type` спершу пробує `wtype`. KDE його не підтримує, тож там результат вставляється через Shift+Insert за допомогою `ydotool` (потрібні `ydotoold` і `/dev/uinput`) або `xdotool`. Із `xdotool` Plasma раз за сеанс просить дозволити керування пристроями введення. Якщо нічого не спрацювало, результат лишається в буфері.

## Файли

Усе лежить у `~/.config/selkit`:

| Шлях | Що це |
|---|---|
| `translit/*.rules` | Власні [правила транслітерації](translit.md) |
| `locales/*.po` | Власні [переклади](translating.md) |
| `plugins/` | [Плагіни](plugins.md), кожен у своїй папці |
| `config.json` | У Linux з нього беруться лише `language` (`"uk"`, `"en"`; без нього — мова системи) і `plugins` |
| `last-action` | Дія для `repeat` |
